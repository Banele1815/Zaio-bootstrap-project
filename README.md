# 🌐 Personal Portfolio Website

A responsive personal portfolio built using **HTML5, CSS3, and Bootstrap 5**.  
This project showcases my skills, projects, and contact information in a clean, modern layout.

## 📂 Features

### 🏠 Hero Section
- Full-screen landing section
- Background image with dark overlay
- Centered introduction text
- Sticky navigation bar

### 👤 About Me
- Profile image and personal details
- Skills displayed using Bootstrap badges
- Clean two-column layout

### 📁 Projects Section
- Responsive 3-column grid (desktop)
- Project cards with images and descriptions
- Live demo buttons and code links

### 📬 Contact Section
- Social media icons (Instagram, GitHub, LinkedIn)
- Contact form with validation fields
- Clean and centered layout

### 🧾 Footer
- Simple dark footer with credit text

---

## 🌙 Bonus Features

- Auto dark mode using `prefers-color-scheme`
- Responsive design (mobile, tablet, desktop)
- Smooth scrolling navigation
- Accessible form structure

---

## 📱 Responsive Design

This portfolio is fully responsive and works on:
- Mobile devices (360px+)
- Tablets
- Desktop screens
- Large displays (4K ready)
